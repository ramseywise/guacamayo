# Reflection — 2026-07-28 15:17

## The Arc

This session started as cross-repo review — /workflow-review across four repos — and became an infrastructure hygiene session. The reviews surfaced blocking findings (BLE001 blind except, stale help text, pass-path telemetry, jq guards), but the real work came after: CI failures that passed locally.

Two systemic patterns emerged:

**Ruff version skew.** Pre-commit pinned at v0.11.2 while pyproject.toml resolved v0.16.0 via uv. CI runs `uv run ruff check` (pyproject version), not pre-commit's pinned version. New rules (RUF059, UP042) and stricter I001 in 0.16 flagged imports that 0.11 allowed. The gap grows silently — every `uv sync` in CI pulls the latest while pre-commit stays frozen. Fixed by bumping all five repos' `.pre-commit-config.yaml` to v0.16.0.

**Hardcoded local paths.** 48 tests used `/Users/wiseer/workspace/guacamayo` as `cwd` for subprocess calls. Invisible failure — works perfectly on the development machine, crashes on CI's `/home/runner/work/guacamayo/guacamayo`. Replaced with `REPO_ROOT = str(Path(__file__).resolve().parent.parent.parent)` in conftest.py.

A third structural gap was identified but not fixed: AIT's template code is excluded from local lint (`exclude: ^template/` in pre-commit) because it contains Jinja2 syntax. Only CI (render → lint) catches issues. This is a known limitation — filed as part of #53.

## How I Worked

The diagnostic approach was clean: read CI logs → identify root cause → targeted fix. The `replace_all` pattern across test files was efficient — one conftest constant, 10 files updated, zero manual per-file editing beyond the import line.

The session spanned compaction — context was lost and had to be reconstructed from the summary. The summary was thorough enough that no work was lost, but the transition added friction.

## What I Know Now

Environment-coupling bugs are a class of their own. They're invisible during development (everything works), invisible during review (the code looks fine), and only surface when the environment changes. The fix is always the same pattern: derive paths dynamically, pin versions consistently across all execution contexts.

The fleet is now consistent on ruff v0.16.0 across all five Python repos. CI exists for guacamayo for the first time. The pre-commit ↔ CI gap is closed — for now. It'll reopen the next time pyproject.toml ruff version bumps without a corresponding pre-commit rev bump.
