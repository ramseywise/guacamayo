- [discovered] A timed dry run is a better toolkit test than a review. galactus asked "can we prototype a classifier in under an hour?" and ran it on real data — 3 of 4 stages worked, training was broken, experiment tracking did not exist. The break was the *composition layer*: `run_classification` had zero definitions repo-wide while every step it composes was independently unit-tested and green. - [discovered] When a "keep" decision and a "ship" decision are gated on *different* predicates, opting into a capability silently discards it. AIT's copier renders everything into `_scaffold/`, then promotion tasks `cp`/`mv` roots out and the staging dir is deleted — anything staged but not promoted vanishes with no error. Cleanup tasks were gated on capability flags (`include_rag_agent`, `has_corpus_pipeline`); promotion tasks on shape flags (`not is_ml_shaped`). An ml_model render that opted into rag_agent kept three trees staged and threw all three away. The same bug had already been fixed once for `nbks/` and the comment recording that fix was sitting six lines above the next instance. Generalization: a two-phase pipeline where phase 1 decides *retain* and phase 2 decides *emit* must key both phases off one predicate, and the failure mode is silence — no error, just absence. — 2026-08-14
- [discovered] CI reports the *first* failing assertion in a sequential block; the remaining N−1 are unverified, not passing. Fixed the one the log named, watched it go green, and nearly shipped — the next two assertions in the same block were the same bug in two more places. A green-after-fix on a short-circuiting check set only proves the prefix. Run the whole assertion block locally after a fix, never just the one that was named. — 2026-08-14
- [discovered] `git diff A...B` is not comparable across branches at different distances from main, so set-differencing two `git diff main...X` file lists produces false "unique to X" results. The supersession question ("is everything on A also on B?") has a merge-base-immune answer: enumerate A's files and `git cat-file -e "B:$f"` each one. That test closed a PR in one command after the diff-based reasoning had inverted which branch superseded which. — 2026-08-14
