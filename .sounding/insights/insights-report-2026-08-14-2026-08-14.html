Feature Discovery

Existing CC Features to Try

Based on your usage patterns, these built-in Claude Code capabilities would directly address your top friction points.

🔍 Native Grep/Glob Instead of Bash

Your 18,901 bash antipatterns are almost entirely replaceable. Claude Code's Grep tool supports regex with file-pattern filters. Glob handles directory traversal. Both are faster, cheaper, and don't burn context on shell output.

In your CLAUDE.md or skill SKILL.md, add:

TOOL PREFERENCE RULES:
- File content → Read tool (never `cat`)
- Pattern search → Grep tool (never `grep -r`)
- File listing → Glob tool (never `find` or `ls`)
- Only use Bash for: git, uv/pip, make, pytest, gh CLI
- Never: `cat`, `find`, `ls`, `head`, `tail`, `wc -l`
