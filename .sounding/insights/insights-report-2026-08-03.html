Existing CC Features to Try

Three Features You're Underusing

🔍 Grep & Glob Instead of Bash

You have 14,758 bash calls but only 299 Grep and minimal Glob. Every time you run bash grep -r "pattern" . or bash find . -name "*.py", you're spending 3–5× more tokens than necessary and adding latency. Grep/Glob are native tools designed exactly for this — they return structured results without shell overhead.

Instead of:
bash: grep -r "cartographer" ~/workspace/librarian/tools/
Use:
Grep(pattern='cartographer', path='~/workspace/librarian/tools/', recursive=true)

📋 TodoWrite for Long Sessions

101 long sessions had no TodoWrite — meaning Claude had no structured task list to track against. You already use it in some sessions (session 06404656, 41d21556) and they show better read/edit ratios and fewer errors. The issue is consistency: sessions like e7126a59 (303 min, 16 msgs) went todoless and accumulated 101 bash antipatterns.

Add this to your session-opening prompt:
Before starting, write a TodoWrite with the steps in this plan. Check off each as you complete it.

⚡ /compact Before Context Bloat

You compact 249 times across 103 sessions — but your heaviest wake/grow sessions (77ca8f22: 1,388 min, 11 compacts; 6cee8987: 1,329 min, 7 compacts) show compacts firing reactively at limits, not proactively. 20% of spend at >150k context could be halved by compacting at the 100k mark. Your /compact skill already exists — just trigger it earlier.

Trigger proactive compact in wake/grow sessions:
