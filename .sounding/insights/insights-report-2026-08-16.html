1. Native Grep/Glob Instead of Bash for File Search

Your 37:1 Bash:Grep ratio is the single biggest CE opportunity. Every bash grep -r "pattern" ., find . -name "*.py", or cat file | grep can be replaced with native tools that don't consume context or require a shell spawn. This would cut your 28.3 bash antipatterns/session dramatically.

# Instead of this (bash antipattern): bash: grep -r "workflow_execute" .claude/skills/ bash: find . -name "*.md" -path "*plans*" bash: cat CLAUDE.md | grep -n "hook" # Use these native tools: Grep(pattern="workflow_execute", path=".claude/skills/") Glob(pattern=".claude/docs/plans/**/*.md") Read(file_path="CLAUDE.md", grep="hook")

Add this to your global CLAUDE.md: "Prefer Grep/Glob/Read tools over Bash for file search operations. Only use Bash when shell execution or pipes are genuinely required."
