Cost & Efficiency

Am I spending well? What's driving cost?

How to read this: Cost is measured in "cost units" — each unit is roughly the price of reading 1M input tokens. Output tokens cost 5× more than input, so a session that writes a lot costs far more than one that reads a lot. Cache hits reduce input cost to near zero. The key lever is fewer output tokens per session and higher cache rates.

Context Health

Is context under control? Are sessions staying lean?

The 150k cliff: Sessions that grow past 150k context tokens cost 5× more per turn because the overflow can't be cached. In early July, 66-75% of sessions were hitting this cliff. The goal is <30%. Compaction is the mechanism — it compresses prior conversation to reclaim context space. Autocompact was broken Jul 15-18 (zero auto-triggered compactions despite sessions reaching 300k–557k tokens) and fired reliably every day since Jul 19 in the transcripts examined — but Ramsey reports it not firing in terminal mode (Jul 30 and again Jul 31). The Jul 30 investigation that found "no defect" read a VS Code session, so it never covered that surface. Treat this claim as contested pending a terminal-mode transcript.
