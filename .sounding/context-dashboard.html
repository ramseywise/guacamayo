The Guacamayo Loop

Five nodes, one cycle. Every session generates telemetry; hooks enforce guardrails and record events; the metacognition skills derive patterns and propose changes; the retro graduates hypotheses into permanent config; improved config shapes the next session.

System Design

Three planes, one cycle. Plane 1 is where work happens — triage shapes an issue until it passes Definition of Ready, execute implements it, review measures it against Definition of Done. Plane 2 observes: the state board and identity lifecycle both write records, telemetry appends them, insights derive patterns, and a verification gate stands between a dashboard number and a retro hypothesis. Plane 3 is what retro actually changes — the four levers of the Claude setup, which shape every session on the planes above. Every box is a skill or module that actually fires; colour tracks which plane a record came from.

Plane 1 — triage → execute → review; triage and review each emit a record
Plane 2 — identity + board feed telemetry → insights → gate → retro
Plane 3 — the four levers a retro can pull

The state board sits in metacognition because it is a record, not a stage of work — triage writes to it via board.py, and /meta-wake and /meta-retro open and close issues directly. Dashed elements are stages that exist but are not automated — see Loop Health.

Where did the tokens go, and what did that effort buy?

North star Keep median cost per session declining while cache hit rate stays above 95%. Output tokens are the primary cost lever — fewer, denser responses beat long ones.

Effort is reported in cost units (input-price-relative), never USD — the weights are model-blind, so a dollar figure would be a lie. Cost is attributed to where effort was spent (repo, skill, subagent), not to work produced: Ramsey commits, so there is no commit→session join and any cost-per-commit ratio would read as Claude-authored output.

Session Health

How did my sessions actually run — and what pushed back?

North star Sessions run lean and land in one pass: peak context under the 150k cliff, few repeated turns, parallelism used where it helps. Friction — interruptions, tool failures, bash antipatterns — trends down; a pattern that recurs 3× gets a hook, not a note.
The 150k cliff: Sessions that grow past 150k context tokens cost 5× more per turn because the overflow can't be cached. In early July, 66-75% of sessions were hitting this cliff. The goal is <30%. Compaction is the mechanism — it compresses prior conversation to reclaim context space. Autocompact was broken Jul 15-18 (zero auto-triggered compactions despite sessions reaching 300k–557k tokens) and fired reliably every day since Jul 19 in the transcripts examined — but Ramsey reports it not firing in terminal mode (Jul 30 and again Jul 31). The Jul 30 investigation that found "no defect" read a VS Code session, so it never covered that surface. Treat this claim as contested pending a terminal-mode transcript.
