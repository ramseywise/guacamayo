Data Sources & Integration

How Guacamayo ingests and displays operational signals.

Context Health Telemetry Emitted by cartographer from session transcripts + memory indices. Captures token boundaries, rot, and retrieval diagnostics. Updated after each session compaction.
Cost Tracking Aggregated from Claude API usage logs, prompt cache metrics, and model selection patterns. Daily rollup at 00:00 UTC. Cost / 1k Ops includes cache amortization.
Skill Evaluation Results Automated test suite runs 5× daily across all skills. Pass rate is p50 from last 50 runs per skill. Flakiness = SD of pass rate. Latency from harness instrumentation.
Code Review Findings Extracted from GitHub PR review comments tagged with finding type (correctness/architecture/safety). Resolution time measured from comment timestamp to merge. Precision calculated against human audit sample.
